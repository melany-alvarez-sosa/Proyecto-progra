# Little Things ♡

## Descripción

Little Things es una red social enfocada en la moda, las pequeñas cosas y actividades que pasan o que se tienen conforme va finalizando el día y la creatividad. Es un espacio donde los usuarios pueden compartir sus outfits, publicar fotografías, descubrir nuevas ideas de estilo e interactuar con otras personas. La página busca reunir diferentes gustos y momentos del día a día en un solo lugar.

## Principales características

- **Inicio:** permite visualizar publicaciones y compartir nuevas fotos o textos.
- **Tablero:** muestra publicaciones y contenido compartido por otros usuarios.
- **Mi armario:** permite mostrar outfits y combinaciones de ropa.
- **Playlist Vibes:** permite compartir canciones y contenido musical.
- **Guardados:** permite guardar publicaciones para consultarlas después.
- **Mi perfil:** muestra la información y las publicaciones del usuario.
